# Page: Add / Edit Equipment Listing (Equipment Owner) - Part 3: Design, Aesthetics & Mobile Layout

## Design Notes
- **UI Theme**: Agriculture-related green and white color palette — clean white form container with green input focus borders, agricultural green dropzone highlight, and prominent green action buttons
- **Single-Page Form Layout**: Keep form to a single clean scrollable page rather than multi-step wizard to maximize ease and speed of entry
- **Mobile Experience**:
  - Image upload dropzone is large and tap-friendly on touchscreens
  - Inputs and buttons stack cleanly with touch-friendly heights
  - Visual preview grid adapts into 2-columns on mobile screens
