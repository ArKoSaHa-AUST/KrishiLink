# Page: Equipment Owner Dashboard - Part 2: Workflow & Interactions

## Workflow
1. Owner logs in → lands here
2. Sees pending requests count → clicks to review and Accept/Reject directly from this widget or the full Requests page
3. Clicks "Add New Equipment" → routes to Equipment Listing Form
4. Clicks an existing listing → routes to edit form or Manage Availability page

## Interactions
- Pending requests widget allows Accept/Reject inline via two buttons per row, with a confirmation toast, no page navigation needed for quick decisions
- Summary cards animate count updates when new requests arrive (simple number transition)
